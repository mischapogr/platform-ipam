This packet retains root licence/notice texts for all 25 modules linked into
the published `0.1.0-rc.1` provider, plus the Go 1.26.9 licence.
[The binary record](PUBLISHED_BINARY.json) binds file hashes and the exact
module/version set from [its build metadata](BUILD_INFO.txt).

The dependency set and copied text hashes match the published binary. Complete
package-specific attribution and distribution review remains pending. The
published ZIP contains one executable, and its source mirror contains the
project LICENSE/NOTICE; this packet makes the linked texts available for review.
It does not establish legal compliance or alter the immutable release assets.

Before the next binary release, review the linked-package obligations, correct
the source notices, and retain the required texts with the distribution.
