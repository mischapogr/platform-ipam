Where to resolve the next blocker
  1. Unknown intent: the network owner updates matrix.yaml with required or isolated connectivity, then reruns the assessment.
  2. Unreviewed move: the workload owner chooses which VPC changes and records approval, wave and target allocation key in migration.yaml.
  3. Candidate: the platform operator checks approved-plan.json and protected ranges. A proposed CIDR is advisory.
  4. Reservation: the owning team uses platform-ipam client reserve or Terraform for a Platform-IPAM pool, then imports a fresh CLI verification report. AWS-IPAM-owned pools need their authority handoff.
  5. Migration: the workload team executes its cutover; the operator reruns AWS discovery and this report to see whether the old conflict has disappeared. Network readiness needs separate route and traffic evidence.
